# 测试文档 · Agent CLI Orchestrator

## 1. 运行方式

```bash
cd /Users/stalitz/www/agent-chat
.venv/bin/python tests/run.py            # 跑全部
.venv/bin/python tests/run.py -v         # 详细
.venv/bin/python tests/run.py tests.test_executor   # 跑单个模块
```

> 测试在开始前通过 `tests/base.py` 设置环境变量 `AGENTCHAT_CONFIG` 指向临时文件，
> 因此**不会污染**真实 `data/config.json`。每个用例再用 `fresh_config()` 隔离。

依赖：`requirements.txt` 包含 `fastapi/uvicorn/websockets`；测试额外需 `httpx`
（已装入 `.venv`：`pip install httpx`）。

## 4. 覆盖率与缺口

- **已覆盖**：模型校验、存储 CRUD 与持久化、Fake agent 流式与收敛、编排全流程（交替/上限/收敛/停止/注入/记忆）、**双模式 chat/debate 分支（单 agent 对话、run_end 终止标记、用户消息回显与入库）、暂停真正生效（resume_event 语义）、控制指令无运行会话时返回 error 反馈、agent 执行失败自动中止（错误不进讨论、不落发言）、transcript 拆条合并（user 分界）与 reconcile 删除多余、网关 usage 回填与空流 error**、REST CRUD、WebSocket 启动与错误广播、mock 数据合法性。
- **未覆盖（需真实环境，不计入 CI 默认）**：
  - `claude-code` / `codex` 真实子进程调用（依赖本机 CLI 与模型 key，烧 token）。
  - 真实模型下的多轮收敛质量、打断续写效果（PRD T10，待用户验收）。
